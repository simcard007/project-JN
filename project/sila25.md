# คู่มือการทำงานของระบบจองห้องประชุม

## 1. ภาพรวมระบบ

ระบบนี้เป็นระบบสำหรับจองห้องประชุม โดยผู้ใช้งานสามารถสมัครสมาชิก เข้าสู่ระบบ ดูห้องประชุม จองห้อง ดูรายการจองของตัวเอง ดูสถิติ และดูข้อมูล Profile ได้

ระบบแบ่งผู้ใช้งานออกเป็น 2 ประเภท

- User
- Admin

โดยแต่ละประเภทจะมีสิทธิ์ในการใช้งานแตกต่างกัน

---

# 2. การเริ่มต้นใช้งานระบบ

เมื่อเปิดเว็บไซต์ ระบบจะตรวจสอบก่อนว่าผู้ใช้งาน Login อยู่หรือไม่

ถ้ายังไม่ได้ Login ระบบจะพาไปที่

`login.html`

ถ้า Login อยู่แล้ว ระบบจะสามารถเข้าใช้งานหน้าต่าง ๆ ของระบบได้

ลำดับการทำงานคือ

เปิดเว็บไซต์
↓
ตรวจสอบ Login
↓
ยังไม่ได้ Login
→ ไปหน้า Login

หรือ

Login แล้ว
→ เข้าใช้งานระบบ

---

# 3. การสมัครสมาชิก

ผู้ใช้งานใหม่สามารถสมัครสมาชิกได้ที่หน้า

`register.html`

โดยกรอกข้อมูล

- Username
- Password
- Confirm Password

เมื่อกดปุ่มสมัครสมาชิก ระบบจะตรวจสอบข้อมูลก่อน

## การตรวจสอบ

1. Username ต้องไม่ว่าง
2. Password ต้องไม่ว่าง
3. Confirm Password ต้องไม่ว่าง
4. Password ต้องตรงกับ Confirm Password
5. Username ต้องไม่ซ้ำกับสมาชิกที่มีอยู่แล้ว

ถ้าข้อมูลไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือน

ถ้าข้อมูลถูกต้อง ระบบจะสร้างบัญชี User และบันทึกข้อมูลไว้ใน `localStorage`
