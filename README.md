# project-JN
    # 🏢 Meeting Room Booking System

    ระบบจองห้องประชุมสำหรับจัดการการจองห้องประชุมภายในองค์กรหรือสถานศึกษา

    ผู้ใช้งานสามารถสมัครสมาชิก เข้าสู่ระบบ ตรวจสอบห้องประชุม จองห้อง ดูรายการจอง ดูสถิติ และจัดการข้อมูล Profile ได้

    ระบบแบ่งผู้ใช้งานออกเป็น 2 ประเภท ได้แก่

    - 👤 User
    - 👑 Admin

    ---

    ## 📌 Features

    ### 👤 User

    ผู้ใช้งานทั่วไปสามารถ

    - สมัครสมาชิก
    - Login เข้าสู่ระบบ
    - ดู Dashboard
    - จองห้องประชุม
    - เลือกวันและเวลา
    - เลือกอุปกรณ์ที่ต้องการใช้
    - ตรวจสอบการจองห้องซ้ำ
    - ดูสถานะห้องประชุม
    - ดูรายการจองของตัวเอง
    - ยกเลิกการจองของตัวเอง
    - ดู Profile
    - Logout

    ### 👑 Admin

    ผู้ดูแลระบบสามารถ

    - Login ในฐานะ Admin
    - ดูรายการจองของ User ทั้งหมด
    - ดูจำนวนการจองทั้งหมด
    - ดูจำนวน User
    - ดูจำนวนห้องที่ถูกจอง
    - ดูการใช้อุปกรณ์
    - ตรวจสอบข้อมูลการจอง
    - ลบรายการจอง
    - ดู Profile ของ Admin
    - Logout
